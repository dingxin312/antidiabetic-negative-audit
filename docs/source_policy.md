# Source policy

This repository distributes derived audit material only.

- Original journal articles are not included. Where available, a DOI link and
  the examined file hash are recorded.
- Third-party model files and repositories are not included. Their source
  locations and hashes are recorded in the source inventory.
- Sequences and labels are reported as audit objects, not as a new biological
  database.
- A source file hash identifies the examined snapshot; it does not establish
  that the snapshot was the exact input to a historical model run.
